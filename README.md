# Outsmart the Open

A daily ASX pre-market brief, written each trading morning by a scheduled Claude routine
(see [ROUTINE.md](ROUTINE.md)) and published here as JSON for the FolioScope app.

- `index.json`: every brief, newest first, with the figures the app's archive and trends use.
- `briefs/YYYY/YYYY-MM-DD.json`: one brief per ASX trading day (Sydney date).

A factual market summary, not investment advice.
